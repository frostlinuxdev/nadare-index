# nadare-index

Public version pointers used by [Nadare](https://github.com/frostlinuxdev/nadare)
to skip an expensive probe of the upstream CDN.

Each `<game>/latest.json` is `{"service": "<id>", "latest": <int>, "checked_at": <unix>}`.
Nadare still verifies the pointed manifest really exists upstream before trusting it.

Generated by:

```sh
python -m nadare.backends.czn.update latest --from <installed>
```

The CZN updater reads it via `CZN_MANIFEST_INDEX` (default points here).

## yostar/

`yostar/index.json` maps a Yostar game tag to its normalized direct-download
manifest (`<Tag>.json`: version, CDN base, files with size + CRC-64) and the
launcher art (`<Tag>.media.json`). Published by `scripts/publish_index.py` in
the Nadare repo; the signing salts never leave the machine or CI that runs it.

## webview2/

`webview2/latest.json` lists the SHA-256 of Microsoft's current WebView2
Evergreen installer (`sha256` is newest first, a few previous builds kept).
Nadare downloads the installer from Microsoft and accepts it if it matches its
built-in pin or one of these hashes, so a Microsoft re-issue does not break
installs on older Nadare builds. Refreshed by `scripts/publish_index.py`; it only
re-downloads when Microsoft's size / Last-Modified changes.
